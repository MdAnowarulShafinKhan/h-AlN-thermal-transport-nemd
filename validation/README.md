# Validation outputs

These files are the representative raw/processed validation outputs present in the source archive:

- equilibration temperature/energy and pressure/volume checks;
- armchair/zigzag steady-state cumulative thermostat-energy and temperature-profile checks;
- thermostat driving-force sensitivity runs for 0.02, 0.05, and 0.08 with five supplied repetitions each.

They provide important evidence for representative steady-state behavior, but they are not raw NEMD outputs for every production case in the study.
